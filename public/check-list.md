# Roadmap Fullstack Developer

## 1. Основи
- **HTML, CSS, JavaScript (ES6+)**
- **CSS препроцесори/фреймворки:**
  - Sass
  - TailwindCSS
  - Styled Components
- **Базові інструменти:**
  - Git
  - npm / yarn
  - Webpack / Vite

## 2. Дані та робота з ними
- **Формати:** JSON, CSV, XML
- **Бази даних:** PostgreSQL, MongoDB, MySQL
- **ORM / ODM:** Prisma, TypeORM, Mongoose
- **Кешування:** Redis
- **GraphQL** (альтернатива REST)

## 3. Фронтенд
- React (з екосистемою)
- TypeScript
- **State management:**
  - Redux Toolkit
  - Zustand
  - Recoil
- Next.js (SSR, SSG, ISR)
- **UI бібліотеки:**
  - Material UI
  - Chakra UI
  - Ant Design
- **Анімації:** Framer Motion, GSAP
- **Форми та валідація:**
  - React Hook Form
  - Formik + Yup / Zod
- **Тестування:**
  - Jest
  - React Testing Library
  - Cypress

## 4. Бекенд
- Node.js
- Nest.js (структурований бекенд)
- Express.js (мінімалістичний варіант)
- **API:** REST, GraphQL, gRPC
- **Протоколи передачі даних:**
  - HTTP / HTTPS
  - WebSocket
  - SSE
- **Аутентифікація / авторизація:**
  - Passport.js
  - JWT
  - OAuth2
- **Валідація:** class-validator (Nest), Joi, Zod
- **Документація API:** Swagger / OpenAPI
- **Тестування:** Jest, Supertest

## 5. Мобільна розробка
- Kotlin (Android)
- Swift (iOS)
- React Native (кросплатформенно)
- Expo (для React Native)
- Flutter (Dart) — альтернатива

## 6. DevOps та інфраструктура
- **Контейнери:** Docker
- **Оркестрація:** Kubernetes
- **CI/CD:** GitHub Actions, GitLab CI
- **Хмарні сервіси:** AWS, GCP, Azure
- **Моніторинг:** Prometheus, Grafana
- **Логування:** Winston, Log4js

## 7. Додатково (корисні інструменти)
- **Лінтинг та форматування:** ESLint, Prettier
- **Документація:** Storybook, Docusaurus
- **Локалізація:** i18next
- **Безпека:** Helmet, rate-limiter, CSRF-захист
- **Тестування контрактів:** Pact
